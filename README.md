# Segmential.NET

.NET library (work in progress).

## Branching

Trunk-based GitFlow variant: `main` is the only long-lived branch. Work happens on short-lived
`feature/*`, `fix/*`, `hotfix/*`, `chore/*` (and optional `release/*`) branches created from `main`
and merged back through pull requests. Releases are tagged `vX.Y.Z` on `main`.
